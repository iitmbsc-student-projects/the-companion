SE2001 · Diploma / Programming · 3 credits

System Commands

The Unix command line — shells, files, processes, pipes, and the small tools that compose into large ones.

Instructor Prof. Gandham Phanikumar Term Every term Prereq none

§ 1Syllabus

what the course promises to cover

This course introduces command-line usage and progresses to automating complex tasks in a Linux environment. With tools like WSL on Windows and bash on macOS, these concepts are widely applicable. Students learn to combine commands, use I/O redirection, and write shell scripts to solve complex problems efficiently - often without needing specialized programs or graphical interfaces. By the end, they will appreciate the power, brevity, and efficiency of the command line, while gaining deeper insight into how their systems work.

§ 3Week-by-week

the official syllabus, week by week

Week 1: Linux virtual machine setup; Command-line environment; Basic Linux commands.

Week 2: Linux commands (advanced); Shell variables; Process management.

Week 3: Combining commands and file handling; Input/output redirection; Software management.

Week 4: Redirection and pipes; Regex (egrep); File search (find); Editors; Bash scripting.

Week 5: Shell scripting - variables, arguments; Conditionals, loops, functions; Scheduled tasks.

Week 6: AWK - text processing, data analysis; Regular expressions in AWK; AWK as a programming language; Introduction to sed; Pattern matching and substitution using regex.

Week 7: Build tools (make); File compression; Networking (IP , ports, DNS); Diagnostics; Log analysis.

Week 8: RAID; Git - workflow, branches, pull requests; Collaboration and issue management.
