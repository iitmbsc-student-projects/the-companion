§ 1Course Description

what the course promises to cover

Building a modern application involves multiple components, including the front end, transaction handling, data storage, server communication, and API integration. The courses Modern Application Development I, and II address these aspects through a detailed, evolving case study, introducing relevant programming skills as the course progresses.

§ 3Week-by-week

the official syllabus, week by week

Week 1: Applications and architectures; Web fundamentals and protocols; Web servers and performance; Replit development.

Week 2: Information representation; HTML and CSS (styling, selectors, responsive design); Bootstrap.

Week 3: MVC and views; UI/UX design and usability; Tools and accessibility; Jinja2 and command-line usage.

Week 4: Persistent storage and relational databases; ER diagrams; SQL; Flask.

Week 5: Requests and responses; CRUD; Routes and controllers; Database integration (SQLite, SQLAlchemy); Flask structure.

Week 6: API design and REST; OpenAPI and documentation; Flask-RESTful.

Week 7: Memory hierarchy; Data and database search; SQL vs NoSQL; Scaling; Database security; Logging and debugging.

Week 8: Frontend development; Asynchronous updates; Client-side operations and security; Indexing and full-text search.

Week 9: Access control; Security mechanisms; Sessions; HTTPS; Logging; Introduction to JavaScript.

Week 10: Application testing; Levels of testing; Test generation; Pytest; Flask-Security; Testing practices.

Week 11: Advanced frontend - JavaScript, custom elements, frameworks; DB migration.

Week 12: Application architecture; Services; Deployment and containers.
