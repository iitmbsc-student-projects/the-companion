Syllabus

The official course syllabus, transcribed from the IITM BS Data Science & Applications course booklet.

§ 1Course Description

This course serves as the first formal introduction to programming in the programme. It introduces Python - used throughout the curriculum - while developing foundational problem-solving and algorithmic skills.

Lectures-Tutorials-Practicals-Credits: 4-0-0-4

§ 2Faculty

  • Prof. Sudarshan Iyengar, Department of Computer Science and Engineering, IIT Ropar

§ 3Week-by-week

Week 1: Programming basics - Replit, variables, data types, operators, strings; Common errors.

Week 2: Variables and dynamic typing; Operators and expressions; Strings (methods, escape characters, applications); Conditional statements (if, else, elif); Importing libraries.

Week 3: Iteration - while, for, nested loops; Range; Loop control (break, continue, pass); Formatted output; Applications.

Week 4: Lists, sets and tuples; List comprehensions; Introduction to functions; Function types and arguments.

Week 5: Dictionaries; Functions and scope; Iterators and generators; Functional tools; Applications (sorting, matrix multiplication).

Week 6: Practice Problems I

Week 7: Practice Problems II

Week 8: File handling - reading and writing; Handling large files; Applications (Caesar cipher, genetic sequences).

Week 9: Recursion - concepts and applications; Recursive problem solving (searching, sorting); Binary search (iterative and recursive).

Week 10: Exception handling; Introduction to object oriented programming; Classes and objects; Attributes and methods; Inheritance and method overriding.

Week 11: Numerical and data libraries - NumPy, Pandas (Series, DataFrames); Data visualization with Matplotlib.
