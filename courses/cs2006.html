The official course syllabus, transcribed from the IITM BS Data Science & Applications course booklet.

§ 1Course Description

Building a modern application involves multiple components, including the front end, transaction handling, data storage, server communication, and API integration. The courses Modern Application Development I, and II address these aspects through a detailed, evolving case study, introducing relevant programming skills as the course progresses.

Lectures-Tutorials-Practicals-Credits: 4-0-0-4

§ 2Faculty

  • Prof. Nitin Chandrachoodan, Department of Electrical Engineering, IIT Madras
  • Mr. Thejesh GN, Independent Technologist, Multiple Affiliations

§ 3Week-by-week

Week 1: JavaScript fundamentals - syntax, variables, control flow and functions; DOM API.

Week 2: JavaScript - collections, iteration, modularity; Prototypes and classes; Asynchrony; JSON and APIs.

Week 3: Frontend implementation; Introduction to Vue.js.

Week 4: Introduction to Vue.js and its components.

Week 5: Using APIs; Vue.js lifecycle; Asynchronous JavaScript (async/await); Fetch API; API calls in Vue.js.

Week 6: Persistent storage; Vue.js - validation, components, testing, routing.

Week 7: Advanced state management; Vuex; Routing in Vue.js; Single-page applications (SPAs); Single-file components.

Week 8: API design and GraphQL; JAM approach; Authentication; Vue-Flask integration.

Week 9: Web servers; Message queues; Asynchronous tasks with Celery; Redis; Celery integration with Flask.

Week 10: Messaging - webhooks, push to client; Server-sent events.

Week 11: Performance measurement and caching.

Week 12: Security - privacy, frontend, backend; CORS and cookies.
