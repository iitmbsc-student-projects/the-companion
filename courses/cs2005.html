Syllabus

The official course syllabus, transcribed from the IITM BS Data Science & Applications course booklet.

§ 1Course Description

This course uses Java to develop an understanding of core concepts such as object-oriented programming, exception handling, event-driven programming, concurrent programming, and functional programming.

Lectures-Tutorials-Practicals-Credits: 4-0-0-4

§ 2Faculty

  • Prof. Madhavan Mukund, Director, Chennai Mathematical Institute

§ 3Week-by-week

Week 1: Orientation; Java basics - types, memory; OOP - abstraction, classes and objects.

Week 2: Java basics; Data types; Control flow; Classes and objects; Input and output.

Week 3: OOP - inheritance, polymorphism; Class hierarchy; Subtyping; Modifiers.

Week 4: Abstract classes and interfaces; Encapsulation and controlled interaction; Private classes; Callbacks; Iterators.

Week 5: Polymorphism; Generic programming; Generics and subtyping; Runtime behavior of generics.

Week 6: Indirection and abstraction; Collections - abstraction, concrete collections, maps.

Week 7: Error handling - exceptions, assertions; Packages; Logging.

Week 8: Cloning; Type inference; Functional programming (higher-order functions, streams).

Week 9: Optional types; Stream processing and result collection; Input/output streams; Serialization.

Week 10: Concurrency - threads, race conditions; Synchronisation (mutual exclusion, test-and-set, monitors).

Week 11: Concurrency in Java - threads and monitors; Concurrent programming examples; Thread-safe collections.

Week 12: Graphical user interfaces; Event-driven programming; Swing toolkit; GUI examples.
