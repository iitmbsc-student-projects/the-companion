Syllabus

The official course syllabus, transcribed from the IITM BS Data Science & Applications course booklet.

§ 1Course Description

This course provides a comprehensive introduction to databases and PostgreSQL, covering database management and design, along with key topics such as security, integrity, and concurrency.

Lectures-Tutorials-Practicals-Credits: 4-0-0-4

§ 2Faculty

  • Prof. Partha Pratim Das, Department of Computer Science and Engineering, IIT Kharagpur

§ 3Week-by-week

Week 1: Introduction to DBMS; Motivation and need for DBMS.

Week 2: Relational model; Introduction to SQL.

Week 3: SQL examples; Intermediate SQL; Advanced SQL.

Week 4: Formal relational query languages; Entity - Relationship (ER) model and database design.

Week 5: Database design - functional dependencies, keys, closure, canonical cover; Lossless join and dependency preservation.

Week 6: Normal forms; Multivalued dependencies and 4NF; Database design case studies; Temporal data; Problem solving on normalization.

Week 7: Application architecture; Web applications; SQL integration with programming languages; Python with PostgreSQL.

Week 8: Algorithms and complexity; Data structures; Storage and file structures.

Week 9: Indexing techniques; Hashing; Index design; B-trees and B+ trees.

Week 10: Transactions - serializability, recoverability; Concurrency control.

Week 11: Backup techniques; Recovery mechanisms; RAID and fault tolerance.

Week 12: Query processing and optimization; RDBMS architecture; NoSQL; DBMS overview and summary.
