Want to contribute?

This site is kept by students, and every course page can get better. Here are three easy ways to help.

  • Share a resource

    Notes, previous year papers, playlists or any link that helped you. Send the link with the course name and how you want to be credited.

    Message on Discourse ↗Email me

  • Report a broken link or a mistake

    Wrong date, dead link, missing course detail or a typo. A short note saying which page and what to change is enough.

    Message on Discourse ↗Open a GitHub issue ↗

  • Add it yourself

    The whole site is open on GitHub. Each course is one small data file, so adding a link is a short change you can send as a pull request.

    View on GitHub ↗

Prefer another way? You can also reach me on LinkedIn or vikash.iitmbs@gmail.com.

If I missed your name, I am sorry

So many people helped that I could not keep track of everyone, and every bit of help mattered. If you were left out, please tell me and I will add your name right away.
